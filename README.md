## 🎓 CIT College Website

A simple and responsive college website for Channabasaveshwara Institute of Technology (CIT), Gubbi, Tumkur.

## About The Project

CIT College Website is a responsive static website created to provide students, parents, and visitors with information about the college, courses, facilities, student experiences, and contact details.

The website provides a simple and modern interface with separate pages for different sections of the college website.
